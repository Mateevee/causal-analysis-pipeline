# Data — how to obtain every dataset

The datasets are **not** in the repository (`external_data/` and
`Data/CausalTimeData/Dataset/` are git-ignored). Every path below is
relative to the **repository root**. Run the scripts from there, because
the default paths are relative.

Each loader in `Data/` has a `HOW TO GET THE DATA` / `HOW THE DATA IS
OBTAINED` section in its module docstring with the full details (format,
ground truth, caveats). This file is the checklist.

If a source is missing, the entry points skip it (via
`Data/base.py:load_with_fallback`) and the run does not stop. The console
shows `[WARNING] scenario source '<name>' could not be loaded ...` and the
traceback goes to `logs/scenarios/loading_failures.log`. Check for these
warnings before trusting a run.

## Which script needs which dataset

| Entry point | Datasets it loads (with the default flags) |
|---|---|
| `main.py` | the **development suite**: synthetic_var, tigramite_scm, lorenz96, logistic_maps, **causaltime**, alarm, **netsim** (flags `USE_*_BENCHMARK` in `Config/execution.py`) |
| `main_heldout.py` | the **held-out** datasets: **sachs**, pems_bay, real_climate, petshop, **tep**, **beeline_grn**, **causal_chamber**, dream3, easyvista_it, rcaeval (list `ACTIVE_SOURCES`) |
| `main_granger_te.py`, `main_pcmci_nobh.py`, `main_sensitivity.py` | development suite + held-out datasets (everything above) |
| `main_gpdc.py` | tigramite_scm, lorenz96, logistic_maps, real_climate, pems_bay, **sachs** |
| `main_seed_replication.py`, `main_ablation_patch.py`, `main_run_one_case.py` | generated data only |

Bold = manual download (section 3). Never loaded by an entry point:
`causal_rivers`, `cipcad_uf`, `dream4`, `ess_cryo`, `metr_la`, `nino_bc`,
`nino_barents_kara`, `tuebingen_pairs`.

## Changing where the data lives

Each loader resolves its folder in this order: the `base_dir=` /
`cache_dir=` argument, then the environment variable in the tables below,
then the default `./external_data/...` path. The environment variable
**only takes effect when the calling script does not pass the argument**.

- `main.py` passes the CausalTime folder explicitly, from
  `CAUSALTIME_DIR_PATH` in `Config/execution.py`. Change it there, because
  `CAUSALTIME_DIR` is ignored. NetSim and ALARM are called without a path,
  so `NETSIM_DIR` / `ALARM_DIR` do work.
- `main_heldout.py` passes the folder of sachs, real_climate, tep,
  beeline_grn, causal_chamber, dream3, easyvista_it and rcaeval explicitly,
  from the constants `SACHS_CSV_PATH`, `CLIMATE_CACHE_DIR`, `TEP_DIR_PATH`,
  `BEELINE_DIR_PATH`, `CAUSAL_CHAMBER_DIR_PATH`, `DREAM3_DIR_PATH`,
  `EASYVISTA_DIR_PATH` and `RCAEVAL_DIR_PATH`. Edit those constants, because
  the matching environment variables are ignored. Only pems_bay and petshop
  are called without a path, so `PEMS_BAY_DIR` / `PETSHOP_DIR` work.
- The other scripts reuse these two (they read `Config/execution.py` and
  call `main_heldout._load_scenarios()`), so the same rules apply.

## 3. Manual download — required before running

| Loader | Put the files here | Where to get them |
|---|---|---|
| `causaltime` | `Data/CausalTimeData/Dataset/{medical,pm25,traffic}/{gen_data.npy,graph.npy}` | https://www.causaltime.cc/dataset/ |
| `netsim` | `external_data/netsim/sim3.mat` | https://www.fmrib.ox.ac.uk/datasets/netsim/sims.tar.gz |
| `sachs` | `external_data/sachs/sachs.csv` | cmu-phil/example-causal-datasets (GitHub), converted tab → comma |
| `tep` | `external_data/tep/{datasetTE.csv,TEGroundTruth.txt}` | giovanniMen/CPCaD-Bench (GitHub), folder `TenneseeEastman` |
| `beeline_grn` | `external_data/beeline_grn/BEELINE-data/inputs/Curated/...` | Zenodo, `BEELINE-data.zip` |
| `causal_chamber` | `external_data/causal_chamber/{wt_walks_v1,lt_walks_v1}/*.csv` | causalchamber S3 zips / `causalchamber` package |
| `causal_rivers` | `external_data/causal_rivers/{rivers_ts_bavaria.csv,rivers_bavaria.p}` | CausalRivers/benchmark release `product.zip` |
| `cipcad_uf` | `external_data/cipcad_uf/{DatasetUF.csv,UFGroundTruth.txt,UFIMDGroundTruth.txt}` | giovanniMen/CPCaD-Bench (GitHub), folder `UltraProcessed_Food` |
| `dream4` | `external_data/dream4/insilico_size<S>_<K>_{timeseries,goldstandard}.tsv` | Synapse syn3049712 (free account) |

The commands below are run from the repository root, in Git Bash,
Linux/macOS or PowerShell. Notes on the commands:

- **`curl`:** `curl` and `tar` ship with Windows 10/11. In Windows
  PowerShell 5.1, type `curl.exe` instead of `curl`, because there `curl`
  is an alias for `Invoke-WebRequest`.
- **`mkdir -p`:** in PowerShell it fails with "already exists" if the
  folder exists. That error is harmless.
- **`.zip` files:** these are extracted with `python -m zipfile -e <zip>
  <folder>`, which works on every system. GNU `tar` (Linux) cannot read
  zip files.

### CausalTime — `Data/causaltime.py`

1. Download the generated dataset (domains `medical`, `pm25`, `traffic`)
   from https://www.causaltime.cc/dataset/ (the "Dataset Download" link of
   https://github.com/jarrycyx/UNN). The site is sometimes unreachable;
   try again later or from another network. Keep a backup of the six
   files (~12 MB).
2. Layout:

   ```
   Data/CausalTimeData/Dataset/medical/gen_data.npy
   Data/CausalTimeData/Dataset/medical/graph.npy
   Data/CausalTimeData/Dataset/pm25/gen_data.npy
   Data/CausalTimeData/Dataset/pm25/graph.npy
   Data/CausalTimeData/Dataset/traffic/gen_data.npy
   Data/CausalTimeData/Dataset/traffic/graph.npy
   ```

   Other location: `CAUSALTIME_DIR_PATH` in `Config/execution.py`.

### NetSim — `Data/netsim.py`

```
mkdir -p external_data/netsim
curl -L -o sims.tar.gz https://www.fmrib.ox.ac.uk/datasets/netsim/sims.tar.gz
tar -xzf sims.tar.gz -C external_data/netsim
```

The archive (~49 MB) holds `sim1.mat` … `sim28.mat` at its top level, so
`external_data/netsim/sim3.mat` is created directly. Only `sim3` is used by
default.

### Sachs — `Data/sachs.py`

One command (creates the folder and converts tab → comma):

```
python -c "import os, pandas as pd; os.makedirs('external_data/sachs', exist_ok=True); pd.read_csv('https://raw.githubusercontent.com/cmu-phil/example-causal-datasets/main/real/sachs/data/sachs.2005.continuous.txt', sep='\t').to_csv('external_data/sachs/sachs.csv', index=False)"
```

Expected header: `raf,mek,plc,pip2,pip3,erk,akt,pka,pkc,p38,jnk` (7466
rows). Path set by `SACHS_CSV_PATH` in `main_heldout.py`.

### BEELINE — `Data/beeline_grn.py`

```
mkdir -p external_data/beeline_grn
curl -L -o external_data/beeline_grn/BEELINE-data.zip "https://zenodo.org/records/19009603/files/BEELINE-data.zip?download=1"
python -m zipfile -e external_data/beeline_grn/BEELINE-data.zip external_data/beeline_grn
```

The zip (~260 MB, MD5 `9ea93065004f2f12022adeeaf3728edd`) already holds
the top folder `BEELINE-data/`, so the result is
`external_data/beeline_grn/BEELINE-data/inputs/Curated/<network>/...`.
The DOI 10.5281/zenodo.3378975 always points to the latest record if the
link above changes. Path set by `BEELINE_DIR_PATH` in `main_heldout.py`.

### Causal Chambers — `Data/causal_chamber.py`

```
mkdir -p external_data/causal_chamber
curl -L -o wt_walks_v1.zip https://causalchamber.s3.eu-central-1.amazonaws.com/downloadables/wt_walks_v1.zip
curl -L -o lt_walks_v1.zip https://causalchamber.s3.eu-central-1.amazonaws.com/downloadables/lt_walks_v1.zip
python -m zipfile -e wt_walks_v1.zip external_data/causal_chamber
python -m zipfile -e lt_walks_v1.zip external_data/causal_chamber
```

MD5: `wt_walks_v1.zip` 19bb4e92cbe0b8dff49299b9b509ac36, `lt_walks_v1.zip`
dcad019186661a56de7a2d1db97fc2f0. Each zip already holds its
`<dataset>/` folder. Files read by default:

```
external_data/causal_chamber/wt_walks_v1/actuators_random_walk_2.csv
external_data/causal_chamber/wt_walks_v1/actuators_random_walk_3.csv
external_data/causal_chamber/lt_walks_v1/actuators_white.csv
external_data/causal_chamber/lt_walks_v1/smooth_polarizers.csv
```

Alternative: `pip install causalchamber`, then
`causalchamber.datasets.Dataset("wt_walks_v1", root="./external_data/causal_chamber", download=True)`
(on a Windows console, set `PYTHONIOENCODING=utf-8` first). Path set by
`CAUSAL_CHAMBER_DIR_PATH` in `main_heldout.py`.

### CausalRivers — `Data/causal_rivers.py`

```
curl -L -o product.zip https://github.com/CausalRivers/benchmark/releases/download/First_release/product.zip
python -m zipfile -e product.zip .
mkdir -p external_data/causal_rivers
mv product/rivers_ts_bavaria.csv external_data/causal_rivers/
mv product/rivers_bavaria.p external_data/causal_rivers/
```

The zip is ~570 MB and extracts into `product/`. Only the two Bavaria files
are needed. You can also point `CAUSAL_RIVERS_DIR` at `product/`.

### DREAM4 — `Data/dream4.py`

1. Create a free account at https://www.synapse.org and open project
   syn3049712 ("DREAM4 - In Silico Network Challenge"), `sub challenge 1`.
2. Download `training data/DREAM4_InSilico_Size10.zip` (and `..._Size100.zip`
   if needed) and `gold standard/DREAM4_InSilicoNetworks_GoldStandard.zip`.
3. From the archives, copy only these files **flat** (no subfolders) into
   `external_data/dream4/`:
   `insilico_size<S>_<K>_timeseries.tsv` and
   `insilico_size<S>_<K>_goldstandard.tsv` (S ∈ {10, 100}, K ∈ 1..5). Some copies
   of the gold standards are named `DREAM4_GoldStandard_InSilico_Size<S>_<K>.tsv`.
   They have the same content, so rename them.

Only size 10 is loaded by default, so you need at least the 10 size-10
files. Env var: `DREAM4_DIR`.
